# Equs

Developer building open-source projects and experimenting with software, Linux, and Android.

I mainly work with C++, Rust, and Python. I also use OpenCode, Supabase, and Vercel in my projects.

## Projects

### [PollyMC](https://github.com/PollyMC-Continued/launcher)
An open-source Minecraft launcher focused on usability, performance, and instance management.

### [Waveyy Android](https://github.com/corecommit/Waveyy-Android)
A native Android music streaming client built with Kotlin, Jetpack Compose, and Material 3.

### [iso-builder](https://github.com/corecommit/iso-builder)
A work-in-progress Rust TUI for customizing Linux ISO images, with plans to support multiple distributions and their specific tools and configurations.
