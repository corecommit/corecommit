# Equs

Developer building open-source software, with a focus on desktop and mobile apps and Linux tooling. I write mostly C++, Rust and Python, and I care about software that is fast, lightweight and pleasant to use.

## Projects

### [PollyMC](https://github.com/PollyMC-Continued/launcher)

An open-source Minecraft launcher focused on usability, performance and instance management. It ships on desktop with a built-in bug reporter, and has its own website and release bot.

### [Waveyy Android](https://github.com/corecommit/Waveyy-Android)

A native Android music streaming client built with Kotlin, Jetpack Compose and Material 3.

### [iso-builder](https://github.com/corecommit/iso-builder)

A work-in-progress Rust TUI for customizing Linux ISO images. It detects what an ISO contains, lets you choose desktops and packages, and generates a reproducible build script. Support for more distributions and their specific tools and configurations is planned.
